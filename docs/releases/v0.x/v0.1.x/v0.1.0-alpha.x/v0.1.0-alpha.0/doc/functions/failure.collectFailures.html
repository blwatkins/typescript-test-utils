    • collectFailures(
          methodToTest: (input: unknown) => unknown,
          scenario: Scenario,
          isEqual?: (expected: unknown, actual: unknown) => boolean,
      ): Failure[]

      Run methodToTest on every input of scenario and collects the inputs that do not produce the expected outcome.

      Parameters

      • methodToTest: (input: unknown) => unknown

        The method to test.

      • scenario: Scenario

        The scenario that holds the inputs and the expected outcome.

      • OptionalisEqual: (expected: unknown, actual: unknown) => boolean

        The optional comparison method for comparing the expected value against the actual value returned. This method should return true if expected and actual are equal or equivalent values. When not defined, expected and actual values will be compared using Object.is.

      Returns Failure[]

      A Failure for each input that does not produce the expected outcome, in input order.

      Remarks

      For a ValueScenario, an input fails when methodToTest returns a different value or throws. For an ErrorScenario, an input fails when methodToTest returns a value or throws an error that is not an instance of the scenario's expectedError.

      • isErrorScenario

      Throws

      When scenario is not a valid Scenario.

      Throws
